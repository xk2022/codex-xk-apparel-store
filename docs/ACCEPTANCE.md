## 2. 本機模型與靜態檢查

以下可用 TypeScript／Node 測試驗證，但不能取代瀏覽器操作或正式後端驗收。精確指令、實際結果與輸出由執行總管完成後填入。

| ID | 情境 | 狀態 | 證據 |
| --- | --- | --- | --- |
| M-01 | 購物車正規化合併 SKU，拒絕未知規格、零／負數／非整數等無效數量 | 通過 | 15項模型測試：SKU合併、未知／無效數量、有限配額 |
| M-02 | 金額、一次運費、免運門檻與整單最長備貨資訊計算正確 | 通過 | 金額與件數安全整數、一次運費、免運門檻、混單最長示意交期 |
| M-03 | 模擬下單重新驗證數量；第一張訂單使用最後一件後，第二張不得再次成功 | 通過 | 最後一件順序競購、先全單驗證再扣庫存、相同訂單ID重試不重扣 |
| M-04 | 同一模擬訂單重複取消不重複回補；COD 未付款不直接套用線上付款取消政策 | 通過 | 取消回補一次、缺失SKU原子失敗、已出貨不可直接取消、COD不自動取消 |
| M-05 | TypeScript 檢查／建置通過，引用檔案存在，沒有遺留錯誤測試標記或正式憑證 | 通過 | npm test 完成tsc與build、離線9圖byte一致、內嵌JS可解析，源碼無外部交易客戶端 |

M-03 僅是單一瀏覽器資料模型的順序操作測試，不代表資料庫鎖、跨分頁同步或多人併發已完成。

## 3. 驗證限制

- 本輪原型沒有正式會員認證、伺服器資料庫、金物流、電子發票、真實通知或正式安全邊界。
- 尚未執行真實瀏覽器視覺／觸控 QA；模型、happy-dom 互動與離線產物測試不能替代瀏覽器驗收。
- 預覽網址可打開／部署成功，不等於購物流程、手機排版或無障礙驗收通過。
- 圖片與文案均為示意；使用權來源另見 [ASSET_SOURCES.md](ASSET_SOURCES.md)。

## 4. 正式上線前另驗

正式會員與管理者權限、真實 DB Migration／交易鎖與庫存保留、最後一件多人競購、回調驗簽與冪等、付款逾時／晚到通知、COD 收款／撥款、退款、未取退回、發票作廢／折讓、真實通知、備份還原、監控及店主實際操作，均須另有測試環境與證據，不能由原型測試勾選代替。
